Respaldo

Copia de seguridad de toda la información del restaurante

Descarga un archivo .sql.gz con la carta, las mesas, el personal, los cupones, los pedidos y las facturas. Guárdalo fuera de este equipo (memoria USB, Google Drive u OneDrive) al menos una vez por semana.

Descargar respaldo

¿Cómo restaurar un respaldo?

  1. Abre phpMyAdmin (en Hostinger: hPanel → Bases de datos → phpMyAdmin).
  2. Selecciona la base de datos del restaurante en la columna izquierda.
  3. Pestaña Importar → elige el archivo .sql.gz → Importar.

Restaurar reemplaza toda la información actual por la del respaldo. Las sesiones abiertas se cierran y el personal debe volver a ingresar.
